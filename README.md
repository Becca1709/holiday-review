# Project Title

Holidays review. Organise your photos into simple albums. create, delete, save, update them as necessary.

## 🚀 Features

- **Simple**: Easy to fill out form with tittle, date and your photos.
- **Full screen**: Wanna see your images bigger, just selected the full screen option.
- **User Authentication**: Secure signup, login, and session handling.
- **Responsive Design**: Optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack

- **Frontend**: Reactjs, Bootstrap CSS, Javascript, React Router.
- **Backend**: Miragejs Mock API
