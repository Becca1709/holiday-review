# 🗺️ Holidays Review

A responsive, multi-page web application designed to seamlessly organize vacation photos into clean, custom albums. Users can create, update, read, and delete albums dynamically while managing their media assets through an intuitive interface.

## Preview

https://codesandbox.io/p/sandbox/holiday-review-v1-4-k4lnxk
---
## Proof of concept
* *Proof of Concept Architecture:* Designed this project with a frontend-first approach using a mock API to perfect the user interface. Features like data persistence (updating records) and file uploads (attaching images) are simulated on the client side, serving as the blueprint for the next phase: integrating a live Node.js/SQL backend.

## 🚀 Features
* 📁 *Simulated CRUD Architecture:* Designed a full Create, Read, Update, and Delete workflow for photo albums; used a frontend-driven mock API to simulate real-time data flow while setting up the architectural blueprint for a live database.
* 🔍 *Immersive Full-Screen Mode:* Instantly expand and view individual photos in a high-resolution, full-screen viewport overlay.
* 🔐 *User Authentication:* Secure user signup, login gatekeeping, and active session state handling.
* 📱 *Responsive Design:* Fluid structural breakpoints optimized for flawless navigation across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

* *Frontend:* React.js, JavaScript (ES6+), React Router (Multi-page routing).
* *Styling:* Bootstrap CSS.
* *Backend:* MirageJS (Mock API server for network simulation).

## 🧠 Key Learning Outcomes

* *Mock API Integration:* Advanced utilization of *MirageJS* to simulate a real-world backend server, handling asynchronous HTTP requests, database seeding, and RESTful route boundaries.
* *Algorithmic Asset Generation:* Engineered a workflow that automatically generates and assigns a high-quality random placeholder image to newly initialized albums to populate empty states creatively.
* *Single Page Application (SPA) Architecture:* Mastered declarative client-side routing using *React Router* to manage clean transitions across a multi-page environment.
* *Clean Architecture:* Kept components separate, organized state data clearly, and made code modular so the project stays readable and easy to update.
